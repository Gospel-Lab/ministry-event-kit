# 포스터 만들기

게시판에 붙일 인쇄용과 단톡방에 올릴 이미지를 **한 번에** 만듭니다.

## 실행

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/make_poster.py" --event event.yml --out out/poster
```

> **윈도우에서는 `python3` 대신 `python` 또는 `py -3` 을 씁니다.**

크기를 바로 지정할 수도 있습니다.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/make_poster.py" --event event.yml --size A2 --out out/poster
```

## 나오는 것

| 파일 | 쓰임 |
|---|---|
| `poster_A3.pdf` | 실측 PDF — 온라인 주문처 |
| `poster_A3_bleed.pdf` | 도련 3mm 포함 — 인쇄소 |
| `poster_A3_CMYK_300dpi.jpg` | 이미지 업로드용 |
| `web_square.png` | **1080×1080** 카톡·인스타 피드 |
| `web_story.png` | **1080×1920** 스토리. 위아래는 앱 화면이 덮으므로 비워 뒀습니다 |
| `인쇄안내.txt` | 규격·용지·인쇄비 |

## 크기 고르기

먼저 **어디에 붙일지** 물어보세요. 크기는 거기서 정해집니다.

| | 크기 | 어디에 | 1장 |
|---|---|---|---|
| `A4` | 210×297 | 나눠주는 홍보지 | 500~1,500원 |
| **`A3`** | 297×420 | **게시판·복도. 가장 흔합니다 (기본값)** | 1,000~3,000원 |
| `A2` | 420×594 | 현관·로비 | 2,000~5,000원 |
| `A1` | 594×841 | 대형 행사, 외부 게시 | 5,000~10,000원 |

## 이 포스터가 지키는 원칙

`${CLAUDE_PLUGIN_ROOT}/docs/design-rules.md` 에 근거와 함께 있습니다.

1. **위계는 크기 차이로 만든다** — 서체를 여러 개 쓰지 않습니다
2. **필수 정보 네 가지** — 행사명 / 날짜·시간 / 장소 / **참여 방법**
3. **여백을 아끼지 않는다**

세 번째가 가장 자주 어겨집니다. 사용자가 "여백이 남으니 더 넣자"고 하면, **꽉 채운 포스터는 아무도 안 읽는다**고 말씀드리세요. 넣을 것이 많으면 포스터가 아니라 리플렛이 필요한 상황입니다.

## QR 코드

`landing.form_url`(또는 `poster.join_url`)에 주소가 있으면 **QR이 자동으로 들어갑니다.**

- QR 라이브러리가 없으면 주소를 글자로 넣고 그렇게 알려줍니다. 포스터는 그래도 나옵니다
- 설치: `pip3 install segno` (윈도우 `py -m pip install segno`)
- **인쇄한 뒤 실제 휴대폰으로 한 번 찍어보라고 반드시 말씀드리세요.** 화면에서 되는 것과 종이에서 되는 것은 다릅니다

## 확인하고 알려줄 것

1. 만든 뒤 `web_square.png` 를 열어 **세 걸음 떨어져서 행사명이 읽히는지** 보세요
2. 신청 방법이 보이는지 — 이게 없으면 포스터가 일을 안 합니다
3. 인쇄비를 알려주세요. A3 30장이면 대략 3~9만 원입니다

## 자주 나오는 요청

- **"글씨가 너무 작다"** — 제목은 글자 수에 맞춰 자동으로 정해집니다. 행사명을 줄이는 것이 가장 확실합니다. `brief.audience: 어르신` 로 두면 잔글씨가 15% 커집니다.
- **"사진을 넣고 싶다"** — 아직 사진 넣는 기능이 없습니다. 만든 PDF를 파워포인트나 미리캔버스에 올려 사진을 얹는 방법을 안내하세요.
- **"색을 바꿔줘"** — `brand` 를 고치면 현수막·명찰까지 함께 바뀝니다. 포스터만 다른 색으로는 만들지 않습니다. 행사 인쇄물이 따로 놀지 않게 하려는 것입니다.
