# 내 컴퓨터 점검

무언가 만들기 전에, 또는 오류가 났을 때 **가장 먼저** 이것부터 돌리세요.
원인을 추측하지 말고 여기서 확인합니다.

## 실행

`PLUGIN_ROOT` 찾는 법: 이 스킬(SKILL.md)과 같은 폴더에 `scripts/` 가 있으면 그 폴더가 PLUGIN_ROOT 입니다. 없으면 이 폴더에서 두 단계 위 폴더(`skills/check` 의 부모의 부모, 하네스가 알려주는 기준 경로에서 계산)가 PLUGIN_ROOT 입니다.

```bash
python3 "$PLUGIN_ROOT/scripts/doctor.py"
```

윈도우:

```
python "%PLUGIN_ROOT%\scripts\doctor.py"
```

(Claude Code에서는 `PLUGIN_ROOT` 가 `${CLAUDE_PLUGIN_ROOT}` 로 자동 치환됩니다.)

`python` 이 없다고 나오면 `py -3` 으로 해보세요. 그것도 안 되면 파이썬이 설치돼 있지 않은 것입니다.

## 결과 읽는 법

| 표시 | 뜻 |
|---|---|
| `[OK]` | 됩니다 |
| `[--]` | 없어도 돌아갑니다. 일부 결과물만 간소해집니다 |
| `[!!]` | **이게 없으면 아무것도 안 만들어집니다** |

`[!!]` 가 하나라도 있으면 그것부터 해결하고, 화면에 나온 설치 명령을 **그대로 복사해서** 알려주세요. 사용자가 직접 실행해야 합니다.

## 항목별로 사용자에게 설명할 말

- **Chrome / Edge** — 필수입니다. 인쇄용 PDF를 만드는 데 씁니다. **윈도우라면 이미 깔려 있는 엣지(Edge)를 그대로 씁니다.** 크롬을 새로 설치하지 않아도 됩니다.
- **Ghostscript** — 없어도 됩니다. PDF는 정상으로 나오고 CMYK 이미지만 건너뜁니다. 인쇄소가 PDF만 받는다면 설치할 필요가 없습니다.
- **Pillow · numpy** — 위와 같습니다. CMYK 색 보정에 씁니다.
- **QR code** — 없으면 포스터에 QR 대신 주소가 글자로 들어갑니다. 포스터를 만들 계획이면 설치를 권하세요.
- **PyYAML** — **없어도 전혀 문제없습니다.** 키트에 자체 파서가 들어 있습니다.
- **Write access** — 지금 폴더에 파일을 못 만드는 상태입니다. 문서 폴더로 옮겨서 다시 하세요.

## 윈도우에서 한글이 깨질 때

키트가 스스로 UTF-8로 출력하지만, 그래도 깨지면 명령 프롬프트에서 먼저 이걸 실행하게 하세요.

```
chcp 65001
```

## 아직 확인되지 않은 것

**이 키트는 맥에서 개발·검증됐습니다.** 윈도우에서 죽을 만한 지점(콘솔 인코딩, 크롬 경로, 고스트스크립트 경로)은 제거했지만 실제 윈도우 검증은 아직입니다.
윈도우에서 문제가 생기면 **깃허브 이슈로 알려달라고** 사용자에게 부탁하세요. 그 제보가 가장 큰 도움이 됩니다.
