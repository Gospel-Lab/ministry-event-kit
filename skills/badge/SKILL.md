# 명찰 일괄 만들기

이름 하나씩 고치지 않습니다. **명단 CSV를 주면 전원 분량이 한 번에** 나옵니다.

## 1. 명단 준비

`participants.csv` — 첫 줄은 반드시 머리글입니다.

```csv
이름,소속,역할
김지훈,1교구,참가자
박은혜,청년부,강사
이수진,중고등부,섬김이
```

- `소속`·`역할`은 비어 있어도 됩니다.
- 역할은 `참가자`(강조색 채움) / `강사`(행사 색 채움) / `섬김이`·`운영`(테두리)로 색이 갈립니다.
- 명찰 색은 현수막·랜딩페이지와 **같은 `brand` 설정**을 따릅니다. 명찰만 색을 따로 줄 수는 없습니다.
- 구글폼으로 신청을 받았다면 **응답 시트를 CSV로 내려받아** 열 이름만 `이름,소속,역할` 로 맞추면 됩니다.

## 2. 실행

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/make_badges.py" \
  --event event.yml --people participants.csv --out out/badge
```

> **윈도우에서는 `python3` 대신 `python` 또는 `py -3` 을 씁니다.**
> 먼저 `python --version` 으로 확인하세요. 아무것도 안 나오면 파이썬이 없는 것이니
> `/event-kit:check` 로 무엇이 없는지 먼저 확인하게 하세요.

## 나오는 것

| 파일 | 쓰임 |
|---|---|
| `badges_print.pdf` | 한 페이지에 한 명 — 인쇄소 발주용 |
| `badges_A4.pdf` | A4 한 장에 4개 — 사무실 프린터로 직접 뽑을 때 (점선이 자르는 선) |
| `back_schedule.pdf` | 뒷면 일정표 — 공통 1장 |
| `인쇄안내.txt` | 용지·코팅·역할 색 안내 |

## 확인하고 알려줄 것

1. 페이지 수가 인원수와 같은지 — `pdfinfo out/badge/badges_print.pdf | grep Pages`
2. **네 글자 이름**이 한 줄에 들어갔는지 (자동으로 글자가 줄어듭니다)
3. A4 몇 장을 뽑아야 하는지 — 4명당 1장

## 알려줄 실무 정보

- 용지는 **아트지 200~250g 무광 코팅**. 유광은 조명이 반사돼 이름이 안 보입니다.
- 명찰은 **한 종류로 찍고 배지 색으로만 역할을 구분**합니다. 남은 명찰을 다음 행사에 그대로 씁니다.
- 이름 글자 높이는 약 16mm로, 1~2m 거리에서 읽힙니다. 명찰의 목적은 장식이 아니라 **이름이 읽히는 것**입니다.
