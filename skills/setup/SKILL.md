# 행사 정보 잡기

행사 하나에 필요한 정보를 **한 파일에 모읍니다.** 이 파일을 고치면 현수막·명찰·랜딩페이지가 전부 따라 바뀝니다.

## 진행 방법

이미 `event.yml` 이 있으면 먼저 읽고 **빠진 항목만** 물어보세요. 없으면 새로 만듭니다.

한 번에 다 묻지 말고 **네 덩어리로 나눠** 물어보세요. 사용자가 모르겠다고 하면 기본값을 제안하고 넘어갑니다.

0. **행사 성격** — 이것부터 묻습니다. 아래 "성격 파악" 절을 보세요
1. **행사 기본** — 행사 이름 / 주최(교회·단체) / 날짜 / 장소 / 문의 연락처 / 단체 색
2. **현수막** — 크기(기본 400×90cm) / 마감 방식 / 제목에서 색을 다르게 줄 단어 / 배치
3. **명찰과 일정** — 명찰 크기(기본 93×124mm) / 역할 종류 / 일정표 / 와이파이·안내데스크
4. **신청 페이지** — 한 줄 소개 / 본문 2~3단락 / 안내 항목 / 구글폼 주소

## 성격 파악 — 가장 먼저 할 일

색이나 크기를 묻기 전에 **누가 보는 행사인지** 먼저 물으세요.
목록을 늘어놓지 말고 **자연스럽게 두세 마디로** 묻습니다.

> "어떤 분들이 오시는 행사인가요? 그리고 분위기는 차분한 쪽인가요, 신나는 쪽인가요?"

대답을 `brief:` 세 줄로 옮깁니다.

```yaml
brief:
  audience: 어르신     # 어린이 / 청소년 / 청년 / 장년 / 어르신 / 전교인 / 외부초청
  mood: 경건           # 경건 / 활기 / 따뜻 / 장중
  formality: 격식      # 격식 / 보통 / 편안
```

이 세 줄이 **색 묶음·강조색·현수막 배치·배경 무늬·글자 크기**를 정합니다.
사용자가 색을 직접 말하면 그 말이 이깁니다. brief 는 **아무것도 안 정해졌을 때 빈칸을 채우는 것**입니다.

### 대상별로 실제로 달라지는 것

전체 규칙과 근거는 `$PLUGIN_ROOT/docs/design-rules.md` 에 출처와 함께 있습니다 (`PLUGIN_ROOT` 찾는 법: 이 스킬(SKILL.md)과 같은 폴더에 `scripts/` 가 있으면 그 폴더가 PLUGIN_ROOT 입니다. 없으면 이 폴더에서 두 단계 위 폴더(하네스가 알려주는 기준 경로에서 계산)가 PLUGIN_ROOT 입니다. Claude Code에서는 `${CLAUDE_PLUGIN_ROOT}` 로 자동 치환됩니다). 요약하면:

- **어르신** — 글자를 15% 키우고 대비가 높은 색으로 갑니다. 대비 감도는 40세부터 떨어져 80세엔 최대 83% 낮아집니다. **글자를 키우는 것보다 대비가 먼저**라고 사용자에게 설명하세요.
- **전교인·외부초청** — 가장 넓은 나이대가 봅니다. 어르신 기준을 따르는 것이 안전합니다. 외부초청이면 **신청 주소·QR을 크게**.
- **청년** — 좌우 나눔 배치, 대비 강하게.
- **어린이** — ⚠️ 아래를 반드시 읽고 사용자에게 미리 말하세요.

### ⚠️ 어린이 행사는 지금 절반만 됩니다

어린이 디자인의 기본은 **밝은 배경 60% + 밝은 주색 30% + 강조 10%** 인데,
이 키트는 현재 **어두운 배경 + 밝은 글자** 한 가지만 만듭니다.

어린이 행사에 쓰면 **"차분한 어린이 행사물"** 이 나옵니다. 못 쓸 정도는 아니지만
여름성경학교에서 기대하는 그림은 아닙니다.

**만들기 전에 이렇게 말하세요.** 조용히 어두운 포스터를 내놓지 마세요.

> "지금 이 도구는 어두운 바탕 디자인만 만들 수 있어서, 어린이 행사에 딱 맞는
> 밝고 알록달록한 느낌은 아직 안 나옵니다. 차분한 쪽으로 만들어 드릴까요,
> 아니면 밝은 디자인이 필요하시면 다른 방법을 찾아볼까요?"

## 파일 쓰기

`examples/event.yml` 을 본으로 삼아 사용자의 작업 폴더에 `event.yml` 로 씁니다.
`$PLUGIN_ROOT/examples/event.yml` 에 전체 항목과 주석이 들어 있습니다.

지켜야 할 것:

- **일정은 `1일차 8/3 월 | 14:00 등록 · 개회예배` 형식**으로 씁니다. `|` 앞은 날짜 묶음, 뒤는 시간과 내용입니다. 이 형식이라야 명찰 뒷면과 랜딩페이지에서 날짜별로 묶입니다.
- 마감 방식은 `봉미싱 / 막대가공 / 족자 / 금속링 / 고무 / 사방미싱 / 없음` 중 하나입니다. **마감에 따라 글자 여백이 자동으로 달라집니다** (봉미싱은 좌우 15cm까지 접힙니다).
- **색은 세 가지 방법이 있습니다.** 단체 상징색이 있는지 먼저 물어보세요.
  - `brand.palette` — `plum`(보라) `navy`(남색) `forest`(녹색) `wine`(자주) `slate`(청회색) `clay`(황토)
  - `brand.accent` — 강조색만 따로. `gold / silver / white / copper` 또는 `"#e0b96a"`
  - `brand.colors.base` + `brand.colors.accent` — 단체 상징색이 있으면 이쪽입니다. 색 코드를 주면 나머지는 전부 계산됩니다. **바탕색은 어두운 색**이라야 합니다.
- 현수막 배치는 `banner.layout` 으로 정합니다. `center`(가운데·기본) / `left`(오른쪽에 로고 자리) / `split`(왼쪽 제목·오른쪽 날짜).
  배경 무늬는 `banner.motif` — `circuit`(기본) / `grid` / `dots` / `plain`.
- 아직 모르는 값은 비워두거나 `미정`으로 두고 넘어가세요. 나중에 채우면 됩니다.

## 다 만든 뒤

무엇을 만들지 물어보고 해당 스킬로 넘어갑니다.

- 현수막 → event-kit 의 banner 스킬
- 명찰 → event-kit 의 badge 스킬 (명단 CSV가 필요합니다)
- 신청 페이지 → event-kit 의 landing 스킬
- 전부 → event-kit 의 all 스킬
