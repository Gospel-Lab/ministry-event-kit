# 신청 랜딩페이지 만들기

`event.yml` 하나로 **모바일 우선 한 페이지**를 만듭니다. 외부 라이브러리가 없어 폴더째 올리면 바로 열립니다.

## 실행

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/make_landing.py" --event event.yml --out out/landing
```

## 나오는 것

- `index.html` — 페이지 본체 (히어로 · 본문 · 안내 · 일정 · 신청 버튼)
- `fonts/` — 글꼴. **폴더째 옮겨야** 다른 컴퓨터에서도 같게 보입니다
- `배포안내.txt` — 구글폼 연결과 배포 절차

## 구글폼 연결

`event.yml` 의 `landing.form_url` 에 주소를 넣고 다시 실행하면 됩니다.

폼 주소는 **[보내기] → 링크 → URL 단축 → 복사**로 얻습니다. 편집 화면 주소를 넣으면 남이 열지 못합니다.

버튼은 **본문과 화면 아래 고정, 두 곳**에 있습니다. 스크립트가 두 곳을 같이 채우므로 손으로 고칠 때만 주의하면 됩니다.

## 배포

`vercel.com/drop` 에 결과 폴더를 통째로 끌어다 놓습니다. Git도 명령어도 필요 없습니다.

- 파일 이름은 반드시 `index.html`
- **드롭할 때마다 새 주소가 생깁니다.** 내용을 다 채운 뒤 마지막에 한 번 올리세요
- 사진을 넣었다면 파일 이름에 한글·공백을 쓰지 마세요

## 확인하고 알려줄 것

1. 휴대폰 폭에서 글자가 잘리지 않는지 (크롬 헤드리스는 창 최소 폭이 500px이라 그 이상으로 캡처해야 합니다)
2. 신청 버튼이 실제 구글폼으로 열리는지 — **이 확인을 빼먹으면 신청 0명으로 끝납니다**
