# 준비 체크리스트 만들기

행사 준비에서 **빠뜨린 것을 한 장으로** 정리합니다. 총무가 출력해 들고 다니며 하나씩 지우는 용도입니다.

## 1. 무엇을 넣을지 정하기

`event.yml` 의 `checklist` 항목에 적습니다. 사용자가 단톡방 대화·회의록·기존 자료를 주면 **거기서 아직 안 끝난 일만 골라** 채우세요. 이미 끝난 일·일부러 안 하기로 한 일(예: "이름표는 패스")은 넣지 않습니다.

```yaml
checklist:
  title: 준비 체크리스트 (총무 확인용)
  facts:                       # 위쪽 요약 상자 — 머리 | 내용
    - 일정 | 09:00 출발 → 막동사랑교회 예배 → 12:00 점심 → 17:00 귀가
    - 버스 | 충북70바0000 · 기사님 010-0000-0000
  todo:                        # 묶음 | 할 일 | 담당(선택)
    - ① 순서지 수정 (10/14 출력 전) | 장소명 **막동사랑교회**로 고치기
    - ② 인원 연락 | 식당 인원 **30명** 재확인 | 회계
    - ③ 당일 가져갈 것 | 출석부 · 볼펜
```

- **묶음** 은 처음 나온 순서대로 한 칸에 모입니다. 기한(예: `10/14 출력 전`)을 묶음 이름에 넣으면 한눈에 보입니다
- **담당** 은 오른쪽에 작게 붙습니다. 총무 본인 일이면 비워 두세요
- `**굵게**` 로 감싸면 굵게 나옵니다. 틀리기 쉬운 이름·숫자에만 쓰세요
- `facts` 를 비우면 `dates`·`place`·`schedule`·`contact` 로 채웁니다
- `todo` 를 비우면 기본 준비 순서(D-30 기획 → D-14 예약 → D-3 점검 → 당일 가져갈 것)로 만듭니다

## 2. 실행

`PLUGIN_ROOT` 찾는 법: 이 스킬(SKILL.md)과 같은 폴더에 `scripts/` 가 있으면 그 폴더가 PLUGIN_ROOT 입니다. 없으면 이 폴더에서 두 단계 위 폴더(하네스가 알려주는 기준 경로에서 계산)가 PLUGIN_ROOT 입니다. (Claude Code에서는 `${CLAUDE_PLUGIN_ROOT}` 로 자동 치환됩니다.)

```bash
python3 "$PLUGIN_ROOT/scripts/make_checklist.py" --event event.yml --out out/checklist
```

> **윈도우에서는 `python3` 대신 `python` 또는 `py -3` 을 씁니다.**

## 확인하고 알려줄 것

1. **한 장에 들어갔는지** — 넘치면 글자를 78%까지 줄여 맞추고, 그래도 넘치면 경고가 뜹니다. 그때는 끝난 일을 빼거나 묶음을 줄이세요
2. 전화번호·계좌번호가 들어갔다면 **공유할 때 받는 사람을 가려 달라고** 말씀드리세요
3. 대화에서 추정한 값(시간·수량 등)은 **추정이라고 따로 짚어** 주세요. 체크리스트는 틀린 값이 그대로 실행되는 문서입니다
